# 形成研究 idea 与初步方案

把研究者已有的问题、材料和判断压缩成一个准备继续的候选选题，以及可交给后续验证的初步方案。最终交付是 `选题交接包`；它必须标记为“选题形成完成，尚未验证”，不是完整开题报告、已经成立的创新点或验证结果。

## 0. 检查依赖与任务边界

开始任何实质工作前，检查当前环境是否提供 `grilling` 和 `domain-modeling`。任一核心依赖缺失时，读取 [`references/COLLABORATION.md`](references/COLLABORATION.md) 的安装响应，提醒用户安装并停止；不要静默降级成人工模拟。`grill-with-docs` 是推荐安装的用户调用入口，不由本 Skill 自动调用。

如果用户已经给出明确创新点和初步方案，且当前要解决的是“它是否成立、怎样做最短 0→1 验证”，说明本 Skill 的上游工作已完成，提醒用户自行调用 `$validate-research-idea`。如果该 Skill 不存在，说明下游缺失，但不要重新做选题形成。

完成条件：核心依赖可用；任务确实是形成、比较或深化选题，而不是验证既定创新点。

## 1. 确认入口与阶段协作契约

先读取用户提供的材料、仓库和已有记录，能查到的事实自行查找。保留研究者原话，判断最接近当前状态的入口：

1. 只有问题或宽泛方向；
2. 已有文献池；
3. 已有候选选题。

从最接近已有工作的入口继续，不强制从检索重来。调用 `grilling`，一次只提出一个会改变方向或工作路径的问题，并给出推荐答案和理由。先确认本轮任务或方向、预期交付、现实约束与可用材料；事实由 Agent 查找，价值、兴趣、现实优先级和最终方向由研究者决定。

把共识写成阶段协作契约：

- 当前目的与入口；
- 本轮材料及证据范围；
- Agent 可以继续完成的可追溯工作；
- 需要保留的中间产物；
- 当前唯一阻塞前沿；
- 哪些变化必须暂停并交给研究者决定。

这是第一个固定决策门。研究者确认前不创建状态目录。

完成条件：研究者确认任务或方向和交付边界；入口、约束、材料范围与唯一阻塞前沿均明确。

## 2. 建立最小状态与单一事实源

优先使用用户指定的工作目录；否则在当前项目中使用 `.scratch/research-ideas/<slug>/`。`<slug>` 只取自用户确认的表述。确认第一个决策门后才按需创建：

```text
.scratch/research-ideas/<slug>/
├── STATUS.md
├── literature/
├── batches/
├── synthesis.md
├── candidates.md
└── research-idea-handoff.md
```

只创建当前阶段需要的文件。`STATUS.md` 是低分辨率地图，只记录目的地、入口与阶段、决定摘要及其链接、当前阻塞前沿、等待回传、尚不能精确化的事项和明确不在范围内的事项。详细内容只在对应权威文件中维护；原始论文和用户文件只保存路径或稳定编号，不复制进状态目录。

新证据要求回退时，保留既有记录并增量修订；不要覆盖来源、阶段报告、候选原稿或研究者决定。

完成条件：状态位置唯一；当前事实、推断、决定与未知项有清楚归属；没有为了“完整”预建空文件。

## 3. 搜：用真实结果校准材料边界

只有方向需要校准、现有池明显不足，或后续暴露特定证据缺口时才进入本步骤。进入前完整读取 [`references/SEARCH.md`](references/SEARCH.md)。

先对齐当前任务、检索式表达的概念关系与真实返回材料。用钓鱼法取得术语、相邻概念或直接证据，用鲸吞法扩大材料面并检查局部结果是否以偏概全；顺序由当前缺口决定。每轮把真实结果、偏差解释和下一轮建议分开记录。

初始结果进入宽泛文献池，用于相关性校准、态势观察和方向选择，不声称逐篇深读。Agent 无法访问数据库时，使用 `SEARCH.md` 的数据库接力检索—检索回传包；未实际执行的检索式只能标为建议。

新增材料已经足以推动当前决定时停止。不要以固定篇数、固定相关率或“查全”为完成条件。

完成条件：当前方向和纳入边界有真实结果支持；已知误检、遗漏风险与证据范围可追溯；研究者确认是否继续当前方向。

## 4. 聚：构建并分析核心文献池

进入核心池处理前完整读取 [`references/LITERATURE-ANALYSIS.md`](references/LITERATURE-ANALYSIS.md)。把不同检索式、数据库和时间批次中服务同一研究任务的材料汇入同一有边界的库，保留形成历史并分配稳定编号。

方向与纳入边界确认后，建立核心文献池。核心池中的每篇材料都必须获得一份可追溯的核心文献分析记录；题录、摘要和全文能支持的判断不同，必须标明证据深度。学科字段按研究目标适配，不把实验学科表格套到理论、计算或人文社科材料上。

按当前 Agent 的稳定输出容量划分动态技术批次，尽量保持单篇完整。每批必须同时产出：

- 本批全部逐篇记录与覆盖清单；
- 完整阶段报告；
- `寻宝导引`：独特想法、矛盾、低频信号、不确定判断、可能影响及来源位置。

第一份阶段报告与研究者共同审阅以校准口径。此后每份完整报告都向研究者开放并进入讨论；研究者可以预先授权连续处理若干批次，但 Agent 不能仅因自认“没有新发现”而省略报告或审阅入口。讨论中出现多个决定时，调用 `grilling` 排序并一次处理一个。

完成条件：核心池每篇材料均被记录或明确列为未完成；每批覆盖完整且可回到来源；研究者已校准分析口径，阶段报告和少数信号均未被最终汇总覆盖。

## 5. 分：综合关系并生成候选

跨批综合必须读取逐篇记录、阶段报告和寻宝导引，并可返回原文核查；不能只读汇总摘要。先把反复出现的趋势、方法、共识、缺口和分歧写入主模式通道，再把独有想法、异常结果、低频路线、关键矛盾、研究者特别关注的判断和重要不确定线索写入少数信号通道。出现频率与研究价值分别判断，每个少数信号都保留来源和去向。

生成候选前完整读取 [`references/CANDIDATE-VIEWS.md`](references/CANDIDATE-VIEWS.md)。让研究者确认一个主视角，再用不同视角做对照审查：

- 前沿或高创新目标：以创新机会为主，以可行性为对照；
- 快速入门、验证或资源受限：以可行性为主，以新颖性和价值为对照；
- 需要打破既有思路：从与材料相关的结构化创新路径中选择，不机械运行全部路径。

目标不清楚时，解释不同选择对候选的影响并一次只请研究者决定一个目标。生成足以比较的少量候选，每份候选都使用 `CANDIDATE-VIEWS.md` 的候选提案契约，并追加独立的候选对照审查。不得用自动总分替代比较，也不得在审查中静默改写原提案。

完成条件：`synthesis.md` 同时保留主模式与少数信号；`candidates.md` 中每份候选均有来源、推断边界、约束、致命不确定性和对照审查。

## 6. 通过候选选择门

把候选及其最强反对理由、替代解释、重复风险、证据缺口、实施代价和失效条件并排交给研究者。调用 `grilling` 一次只处理“本轮准备继续哪一个候选，或应先修改、补搜、暂不继续”这一决定；给出推荐和依据，但由研究者选择。

这是第二个固定决策门。保留所有候选原稿、审查和未选原因，不把未选择写成已证伪。

完成条件：研究者选定并确认一个候选，或明确决定修改、补搜或停止；选定理由与保留的异议可追溯。

## 7. 返回材料池定向深化

选定候选后，完整读取 [`references/HANDOFF.md`](references/HANDOFF.md)。回到完整文献池做定向筛选，必要时补充检索和全文，并深化研究问题、可能机制、初步方法与现实约束。逐篇判断新材料是支持、反驳、限定还是扩展候选。

选题交接包中的关键论断必须回到全文并定位；暂时只有摘要支持的线索可以保留，但必须标为待核查，不得承担关键论证。Agent 推断、作者声明、研究者决定和未知项分别标明。

完成条件：选定候选已经历完整文献池定向复查；关键论断有全文定位；新增冲突、限制和未知项已进入方案，没有被“优化后的完整方案”覆盖。

## 8. 形成并确认选题交接包

复制 [`assets/research-idea-handoff.md`](assets/research-idea-handoff.md) 到状态目录，按 `HANDOFF.md` 的字段与交接门填写。未知项明确写“未知”，不根据流畅性猜测补齐。

把完整交接包交给研究者复核。调用 `grilling` 一次只处理一个会改变交接内容的问题；这是第三个固定决策门。只有研究者确认准确后，才把状态标记为：

> 选题形成完成，尚未验证

然后说明可由研究者自行调用 `$validate-research-idea`，把交接包映射为可验创新点卡并寻找最短验证路径。本 Skill 不自动调用另一个用户调用型 Skill。

完成条件：研究者确认候选和交接包；主视角提案、对照审查、定向深化、关键全文证据、约束、冲突与致命未知项均可追溯；交接状态明确为未验证。

## 全程约束

- 让当前问题和下一步输出控制信息处理；材料足以行动时暂停，后续不落地时回退。
- 人工讨论不限于三个固定决策门。材料改变认识、研究者品味或现实判断时及时交流。
- “研究空白”“高创新”“高可行性”“容易发表”和“未发现重复”都是待核查判断，不是模型生成即成立的事实。
- 不把宽泛池抽样分析写成全池覆盖，不把摘要声明写成全文结论，不把低频等同于低价值。
- 不预载特定学科、数据库、方法、候选课题或用户机器的绝对路径。所有研究内容来自当前用户及其材料。
- 只有追溯规则来源时读取 [`references/COVERAGE.md`](references/COVERAGE.md)；[`references/TEST-CASES.md`](references/TEST-CASES.md) 只用于开发与回归测试，不作为运行时示例或选题素材。
