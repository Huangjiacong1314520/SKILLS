# 方法与执行路由

## 方法主干

把“搜—聚—分”作为循环，而不是一次性流水线：

```text
真实检索 → 增量入池 → 关系分析 → 研究候选
    ↑                         ↓
    └──── 证据缺口与重复风险 ────┘
```

- **搜**：根据当前信息需求选择鲸吞或钓鱼，并利用真实结果修正问题和检索词。
- **聚**：维护一个去重、稳定编号、来源可追溯、可增量更新的主证据池。
- **分**：为当前研究目标选择关系分析视角；分组不追求唯一、客观或互斥的分类。
- **候选**：把来源事实、文献关系和 Agent 推论连接起来；候选是假设，不是已经成立的选题。

方法依据来自“搜聚分验合”原始教材、科研论连载、训练营原始提示词和原始案例。二次整理笔记不作为方法证据。

## 双层诊断

先判断用户在哪里，再决定 Agent 怎么走。

### 认知颗粒度

- `2.1`：对做什么基本没有概念。
- `2.2`：知道大方向，但不知道具体研究什么。
- `2.3`：了解细分方向或问题，但无法继续推进。

### 证据资产

- 无可靠材料；
- 具体问题、现实需求、实验异常或失败信号；
- 已有文献池、锚点论文或初步候选。

## 内部执行路由

- **侦察**：建立术语、版图和第一批有分散度的文献关系。
- **聚焦**：围绕具体问题、异常或需求寻找原因、对策和可借鉴证据。
- **续研**：审计并复用已有文献资产，压缩方向、补证或核查候选。

典型映射：

| 用户状态 | 内部动作 |
|---|---|
| 2.1＋无材料 | 侦察 |
| 2.1＋大文献池但仍无概念 | 续研审计后俯瞰分组 |
| 2.2＋缺可靠版图 | 侦察后转聚焦 |
| 2.2＋已有文献池 | 续研并用关系分析压缩方向 |
| 2.3＋具体问题但证据不足 | 聚焦 |
| 2.3＋锚点、文献池或候选 | 续研 |
| 任意颗粒度＋异常或现实问题 | 聚焦该信号并增量入池 |

路由是 Agent 内部动作，不要求用户准确命名或选择。

对于跨度极大的`2.1`领域，如果用户没有提供导师方向、可用方法、技能资源或锚点论文，先询问一个最能确定边界的问题。用户确实无法回答时，执行领域级侦察并展示多个探索分支，不擅自锁定其中一个子领域。

## 四类起始信号

四类起点不是四套对称工作流，只决定汇入共同主干前的初始动作。

- **好奇**：明确想理解什么；寻找当前工作、未决问题、矛盾和边界。
- **现实问题或需求**：拆解需求、失败或能力缺口；寻找第一批支持和检验项。
- **异常或失败结果**：保留原始异常；列出替代解释和隐藏变量；针对原因检索。
- **文献关系**：分析组合、迁移、冲突、局限和未来工作，同时检查真实价值。
