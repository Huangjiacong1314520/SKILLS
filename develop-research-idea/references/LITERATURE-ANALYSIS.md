# 核心文献分析

只在建立或处理核心文献池时读取本文件。目标是逐篇留下可追溯记录，再进行不会抹去低频信号的跨批综合。

## 1. 宽泛池与核心池

- **宽泛文献池**：校准相关性、观察领域态势、形成聚焦方向。允许只处理元数据或代表性材料。
- **核心文献池**：方向和纳入边界确认后，进入逐篇结构化分析的材料集合。

核心池每篇都必须有记录。未完成的论文进入覆盖清单，不得用抽样结果代表全池。

## 2. 文献证据深度

| 深度 | 可以支持 | 不得直接支持 |
| --- | --- | --- |
| 题录层 | 作者、年份、期刊、题名、关键词、分布趋势 | 研究内容、机制、局限、结果 |
| 摘要层 | 作者在摘要中声明的问题、方法、主要结果与贡献 | 未在摘要出现的细节；可靠的机制、局限、适用边界判断 |
| 全文层 | 方法、结果、局限、条件和可迁移启发 | 超出全文与原始证据范围的推广 |

全文层记录必须给出页码、章节、图表或可复查段落位置。候选可暂含摘要层线索；交接包关键论断必须由全文层承担。

## 3. 核心文献分析记录

每篇记录使用稳定编号，并保留以下固定骨架：

```markdown
## <稳定编号>｜<题名>

- 来源位置与稳定标识：
- 文献证据深度：题录 / 摘要 / 全文
- 研究对象与情境：
- 作者研究问题：
- 方法与证据：
- 核心结果及其直接支撑：
- 作者声明的贡献：
- 作者明确的局限或未知：
- Agent 识别的局限、不确定性或替代解释：
- 与当前研究方向的关系：支持 / 反驳 / 限定 / 扩展 / 背景
- 可迁移启发（Agent 推断）：
- 待核查项：
```

作者陈述与 Agent 判断分开。按当前研究目标增加少量学科字段，例如材料与参数、数据集与基线、评价指标、理论假设与证明边界、样本与测量、文本语料与解释框架；不适用的字段不创建，也不虚构。

## 4. 动态技术批次

批次只解决稳定处理容量，不承担主题分类含义。根据单篇长度、证据深度、文件质量、图表复杂度和当前输出容量确定大小：

- 尽量保持单篇完整；
- 为逐篇记录、覆盖检查、少数信号和完整报告留足空间；
- 不为塞入更多材料压缩记录到无法复查；
- 各批使用同一固定骨架和经研究者校准的适配字段；
- 新增材料分配新编号或保留已有稳定编号，不因重排批次改号。

固定篇数只可能来自特定工具限制，不是方法原则。

## 5. 每批交付契约

每批目录至少保留：

1. **逐篇记录**：覆盖本批全部论文；
2. **覆盖清单**：稳定编号、来源、证据深度、完成状态、待核查项；
3. **阶段报告**：趋势、共同方法、主要分歧、可能缺口和对当前方向的影响；
4. **寻宝导引**：独特想法、异常结果、低频路线、关键矛盾、不确定判断，以及每项的来源编号、位置、证据深度、潜在意义和成立条件。

阶段报告不能替代逐篇记录，寻宝导引不能替代完整阶段报告。

第一批由研究者与 Agent 共同审阅，校准相关性、字段、推断边界和报告口径。以后每批都保留人工审阅入口；研究者可授权连续批次，但报告仍逐批保存并可回看。

## 6. 三种逻辑职责

- **协调**：维护阶段协作契约、材料范围、稳定编号、统一口径、批次边界和研究者沟通。
- **批次分析**：完成本批全部记录、覆盖清单、阶段报告和寻宝导引。
- **跨批综合**：比较全部中间产物，按需返回原文核查，不覆盖原记录，不替研究者选择。

这些是职责，不是固定 Agent 数量。同一 Agent 可以依次承担；环境和任务适合时也可分派多个 Agent，但必须共享口径并保留来源。

## 7. 双通道综合

`synthesis.md` 同时维护：

### 主模式通道

反复出现的趋势、方法、共识、缺口与分歧。每项给出覆盖范围、代表来源和证据深度，不把频率自动解释为价值。

### 少数信号通道

独有想法、异常结果、低频路线、关键矛盾、研究者特别关注的判断和重要不确定线索。每项必须记录：

- 来源编号与位置；
- 证据深度；
- 潜在意义与成立条件；
- 去向：提升为候选 / 保留来源后合并 / 暂存待补证 / 当前排除及理由。

跨批综合可以修正综合判断，不能回写覆盖论文记录或让合并后的表述失去原始来源。
