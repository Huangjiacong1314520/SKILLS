# 抽象行为契约

本文件只用于开发和回归测试，不作为运行时示例或候选素材。测试夹具必须在 Skill 包外生成；每次使用不同学科和不同表述，不能把测试内容固化进 Skill。

## T1｜只有宽泛方向

**给定**：用户只提供 `[宽泛问题或方向]`、若干现实约束，没有文献。

**必须**：识别入口；先查可查事实；一次只问一个方向性决定；研究者确认第一个门前不建状态目录；从用户输入生成检索轴。

**禁止**：注入预设课题、固定数据库、固定方法或示例候选。

## T2｜已有文献池

**给定**：用户提供混合题录、摘要和全文的 `[文献池]`，但没有候选。

**必须**：跳过不必要的重搜；区分宽泛池和核心池；标证据深度；为核心池逐篇记录；动态分批；每批保留覆盖清单、阶段报告和寻宝导引。

**禁止**：用摘要写机制结论；抽样后声称覆盖全池；固定每批篇数。

## T3｜已有候选选题

**给定**：用户提供多个 `[候选]` 和部分来源，希望选择并形成初步方案。

**必须**：保留候选原话；补足可比较的来源与约束；逐候选做不同视角的对照审查；让研究者决定；选定后返回完整材料池定向深化。

**禁止**：自动总分定胜负；静默改写候选；把轻量审查当验证。

## T4｜已经进入验证问题

**给定**：用户已有明确创新点、初步方案和致命未知，询问最短 0→1 验证。

**必须**：说明边界并提醒用户自行调用 `$validate-research-idea`。

**禁止**：重新执行选题生成；在本 Skill 中创建验证档案。

## T5｜证据深度混合

**给定**：一个关键新颖性主张只有摘要支持，次要背景有全文支持。

**必须**：允许候选暂存该线索，但在交接前要求关键主张回到全文；找不到全文时明确未知或降低主张。

**禁止**：用次要全文替代关键论断；把“当前未找到”写成研究空白。

## T6｜数据库不可访问

**给定**：Agent 无法进入用户的 `[受限数据库]`。

**必须**：输出概念式、数据库语法建议、试搜检查和回传字段；用户回传后区分实际执行与 Agent 建议。

**禁止**：声称已经运行；要求用户只发结果数而不发真实查询与代表记录。

## T7｜低频信号

**给定**：多数论文支持主模式，单篇高质量全文出现冲突或异常。

**必须**：主模式和少数信号分开；记录来源、证据深度、成立条件与去向；让研究者看见其影响。

**禁止**：按出现频率自动删除；把低频自动提升为正确结论。

## T8｜依赖缺失

**给定**：环境缺少 `grilling` 或 `domain-modeling`。

**必须**：提供安装命令、最低选择和重新调用说明后停止。

**禁止**：静默模拟核心依赖；因条件依赖缺失而阻塞无关入口。

## T9｜跨学科适配

**给定**：分别使用实验、计算、理论和解释性研究的包外临时材料。

**必须**：固定核心记录骨架不变；只增加适用字段；最终交接字段保持问题、证据、机制或解释、方法、约束和未知项可追溯。

**禁止**：要求所有研究填写材料合成、性能数值、数据集或变量模型。

## T10｜人工校准与连续批次

**给定**：用户允许 Agent 连续处理若干批次。

**必须**：共同审阅第一批；以后逐批保存完整报告和寻宝导引；授权范围内可连续处理；任何改变方向的决定仍暂停。

**禁止**：把连续授权解释为放弃人工判断；因 Agent 自认无新意而省略批次报告。

## T11｜交接完成

**给定**：候选已选定并定向深化，但仍有明确未知项。

**必须**：未知项原样进入交接包；完成全文门和研究者确认后标记“选题形成完成，尚未验证”。

**禁止**：为了模板完整猜测未知；宣称创新、机制或可行性已经验证；自动调用下游用户调用型 Skill。

## T12｜首个长期术语落盘

**给定**：项目尚无 `CONTEXT.md`；Agent 为一个 `[长期复用的研究术语或成功含义]` 提出规范定义，研究者明确同意。

**必须**：在下一个追问前调用 `domain-modeling`；按项目 domain docs 布局惰性创建 `CONTEXT.md`；写入规范术语、紧凑定义及已知应避免的别名；`STATUS.md` 已存在时只记录摘要和链接。

**禁止**：在术语确认前创建空文件；把未确认的 Agent 建议写入领域文档；把 `CONTEXT.md` 放入 `.scratch/research-ideas/<slug>/`；跳过落盘直接进入下一个追问。

## T13｜已有领域语言冲突

**给定**：项目已有 `CONTEXT.md` 或 `CONTEXT-MAP.md`，其中的规范术语与研究者当前用词存在实质冲突。

**必须**：第一次追问前读取相关领域文档；明示旧定义与当前含义的差异；让研究者决定沿用还是修订；确认修订时先更新领域文档，再继续追问。

**禁止**：忽略已有定义；静默使用两套同义词；未经研究者决定覆盖原有领域语言。

## 结构回归检查

- `SKILL.md` 包含完整步骤和逐步完成条件。
- 所有入口都必经的文档化追问闭环直接位于 `SKILL.md`，不依赖条件性参考文件才生效。
- 所有条件性文件由 `SKILL.md` 直接链接，不形成二级导航链。
- 同一规则只有一个详细所有者；`COVERAGE.md` 只映射。
- 包内不存在固定研究主题、用户绝对路径或真实测试夹具。
- `description` 是单行人类可读摘要；隐式调用在 frontmatter 和 `agents/openai.yaml` 中均关闭。
- 资产模板不包含流程规则；`HANDOFF.md` 不复制整张模板。
