# 证据池与来源记录

## 一个主池，多个视图

每个研究任务维护一个`文献来源表.csv`。所有新记录先去重，再分配稳定`RE###`编号。编号一旦分配不再改变。

批次、主题、期刊层级、强相关集合和候选支持集都只是主池视图。视图记录筛选条件和纳入理由，不复制成失去关联的新池。

## 两层记录

### 稳定来源记录

保存论文身份和检索来源：

- 文献编号、标题、作者、年份、期刊；
- DOI、稳定链接或数据库记录号；
- 摘要和关键词；
- 数据库、检索轮次和导入文件；
- 当前材料层级与纳入状态。

### 可增量证据注释

在`证据笔记.md`中保存针对当前任务的内容：

- 作者明确报告的对象、方法、数据和结论；
- 作者明确陈述的局限、争议和未来工作；
- 证据位置：摘要、章节、页码、图表或附录；
- 与当前任务的相关作用；
- Agent 分析和待核查项；
- 关联的关系记录和候选编号。

来源记录不被分析结论覆盖。同一文献可有多条证据注释并服务多个候选。

## 证据层级

- **题录**：用于版图、年代、期刊和主题线索；不足以支持具体结果或局限。
- **摘要**：可支持作者在摘要中明确报告的目标、方法和主要结果；不能推断未出现的实验细节。
- **全文**：用于核查候选关键方法、结果、局限、冲突、边界和未来工作，并记录具体位置。

需要把候选升级为`证据化候选`时，对决定性主张进行全文核查。无需为了形式完整而精读主池中的每篇文献。

## 去重优先级

1. 规范化 DOI 完全相同；
2. 数据库唯一记录号相同；
3. 规范化标题相同；
4. 标题近似但版本不同的记录交给 Agent 判断，并保留合并说明。

预印本与正式发表版可以合并为同一研究的版本记录，但必须保留版本差异和当前引用版本。

## 纳入和排除

每次筛选都记录纳入或排除理由。仅大领域相关、但与当前问题、关系、方法、资源或证据缺口无关的记录，可以排除出当前视图，但仍可留在主池。
