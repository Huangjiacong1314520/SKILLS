# 验：最短验证路径

这是一次早期证伪项目。先找到可能让研究夭折的**生死问题**，再用最低必要投入取得足以继续、修改或放弃的证据。

## 必读与依赖

开始任何工作前，完整读取 [`GUIDE.md`](GUIDE.md) 至 EOF。只有追溯规则来源时读取 [`COVERAGE.md`](COVERAGE.md)；只有需要跨领域迁移实例时读取 [`references/CASES.md`](references/CASES.md)；只有核对原句与来源边界时读取 [`references/source/CORE-EXCERPTS.md`](references/source/CORE-EXCERPTS.md)。

检查当前环境是否提供以下可选增强 Skill：`setup-matt-pocock-skills`、`grill-with-docs`、`grilling`、`domain-modeling`、`wayfinder`、`research`、`prototype`、`diagnosing-bugs`、`handoff`。若存在则按需使用；若缺失，不要停止验证，改用当前 Skill 的内置流程，并在结果中注明哪些增强步骤未执行。只有用户明确要求安装这些 Skill 时，才提示其参考 `https://github.com/mattpocock/skills`。

完成条件：`GUIDE.md` 已完整读取，并已根据当前环境记录可用的增强 Skill、issue tracker 与 domain docs；缺失项不阻断基础验证，但必须在验证记录中标明。

## 1. 恢复或建立状态

如果用户提供验证档案，先读取档案及其直接链接的当前证据和未完成任务；如果只提供创新点，先保留原话，不创建文件。

完成条件：已明确本轮处于可验化、路径设计、证据准备、执行、结果诊断或项目恢复中的哪一种状态。

## 2. 通过可验门

使用 `grilling` 一次只问一个会改变验证路径的问题；能从用户材料、仓库或来源查到的事实自行查找。把模糊创新点加工成 `GUIDE.md` 规定的可验创新点卡，未知项明确标记为未知。

出现术语冲突、研究边界决策或可能形成长期决定时，询问用户是否转入 `$grill-with-docs`。用户同意后，输出 `GUIDE.md` 中的完整交接包并停止；用户返回更新后的术语、决定和文档路径后再恢复。

完成条件：卡片必需字段均有内容或明确未知，用户已确认卡片准确。此时才复制 [`assets/validation-dossier.md`](assets/validation-dossier.md) 创建验证档案。

## 3. 锁定生死问题

审查问题假设与方案假设，判断是否存在独立的 0→1 风险。只为仍可能使研究夭折的假设生成验证路径；已有充分证据或不存在 0→1 风险时写明理由。

完成条件：每个致命不确定性都由既有证据、待执行路径或“不需独立验证”的理由覆盖，并按最先影响决策的顺序排列。

## 4. 设计最短验证路径

先生成若干删减、替代、降维、仿真、复现或理想条件候选，再按 `GUIDE.md` 的最短判据选择。对执行关键的方法、参数和阈值开展最小必要检索；可调用 `research`、`prototype`。每条路径必须满足 `GUIDE.md` 的路径契约和四态判定要求。

完成条件：选中路径具备可观察量、对照、测试有效性检查、检出能力、最简资源、证据状态、Go/Revise/No-Go/Inconclusive 判据，以及每种结果后的动作。

## 5. 推进验证闭环

能在当前环境安全执行的检索、代码、仿真和分析直接执行；需要物理实验、受限数据库、设备或他人协作时，给用户一份只包含当前验证前沿的执行与回传清单。收到结果后先检查数据与测试有效性，再解释假设。

结果异常且测试有效性不足时调用 `diagnosing-bugs`，或按其“重现 → 缩小 → 可证伪假设 → 单变量检查 → 回归验证”纪律处理。每轮都更新同一份验证档案。

完成条件：真实证据已进入档案，判定与证据状态分开记录，下一项验证前沿唯一且可执行。

## 6. 项目升级或退出

验证跨多个会话、存在阻塞等待、需要多人协作或仍有无法精确出票的迷雾时，询问用户是否转入 `$wayfinder`。用户同意后，输出 `GUIDE.md` 中的 destination、notes、frontier 与 fog 交接包并停止；返回地图后按验证档案中的决定恢复。

Go 且生死问题均已覆盖时，说明可以进入 1→10；Revise 更新卡片并回到相应步骤；No-Go 保存证据与放弃理由；Inconclusive 回到诊断，不伪装成结论。

完成条件：验证档案已记录最终或当前判定、决策理由、证据链接、范围边界和下一步；没有真实结果时只声明“路径已准备”。
