# 学术研究搜索

本分支处理文献、检索词、研究思路、idea 重复、参数、代码、实验方法和科学证据。

## 先判断目标

### 主题与检索词探索

目标：从陌生主题中获得专业表达、核心概念组、相邻方向和下一步系统检索边界。

动作：

1. 用直译或自然语言试探。
2. 从高相关结果提取题名、摘要、作者关键词、索引词和具体对象。
3. 区分同义表达、上位词、下位词和不同研究分支。
4. 将候选词逐个加入概念检索式并观察新增结果。

完成标准：已经形成可解释的概念组，知道下一步要系统覆盖什么。

### Idea 重复与遗漏检查

目标：查找与拟议 idea 高度相似的已有工作，并找出能直接帮助执行的关键来源。

动作：

1. 搜索 idea 的直接表述、同义表达和关键关系。
2. 搜索相邻体系中等价的机制或组合。
3. 检查结果前列、相关文献、被引与引用来源。
4. 记录搜索日期、来源范围和仍可能遗漏的区域。

完成标准：高度相似候选均已核验；结论表述为当前范围内“发现”或“未发现”；需要正式查新时已明确转交。

### 参数、代码、实验方法与具体证据

目标：找到可执行、可追溯并带适用条件的具体信息。

动作：

1. 把对象、状态、条件、参数/方法和单位写清。
2. 搜直接体系；无结果时搜索相邻材料、相邻机制或同类实验。
3. 追踪引用与被引来源，优先原始论文、标准、官方数据和可靠手册。
4. 核验数值单位、温度/压力/状态、模型假设、代码版本和实验边界。
5. 已能支持低成本验证时转实践。

完成标准：信息来源、数值或方法、适用条件和验证动作均已明确；无法核验部分保持候选状态。

## 检索动作库

- 先精确后扩大：先题名或最小概念组，再逐个增加同义表达和字段范围。
- 删除测试：去除空泛动词、标点、斜杠和非必要限定。
- 短语测试：比较引号、词序和邻近关系。
- A AND B：把问题/功能与对象/方法分开；必要时加入 C。
- A* 迁移：搜索保留关键机制的相邻体系。
- A = B + C + D：拆开对象、机制、方法、场景和证据。
- 换入口：全文、图片、公式、结构式、引用链、代码仓库或标准数据库。

## 相关性检查

抽查结果并说明：

- 真正回答当前问题的比例和典型类型；
- 主要误检来自哪个概念或字段；
- 已知典型文献为何命中或遗漏；
- 继续扩张会带来什么新价值与新噪声。

## 转入系统方法

当用户要求系统综述、正式查新、法规证据、临床/医学高风险结论或接近穷尽的覆盖时，钓鱼法只负责提供术语与边界。随后使用适当的系统检索、纳排、去重和证据审查流程。
